
# SnackUNIVO

Proyecto final de la materia Programación Estructurada — Universidad de Oriente (UNIVO).

Simulador de máquina expendedora de refrigerios.

## Tecnologías

- Vite
- TypeScript
- HTML
- CSS
- JSON

## Instalación

```bash
npm install
```

## Ejecutar el proyecto

```bash
npm run dev
```
